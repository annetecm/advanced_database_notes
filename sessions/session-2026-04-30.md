## Topics covered
- Backup and restore / migrations: BACKUP DATABASE
- DDL: Data Definition Language subset of SQL used to define, modify, and manage the structure of objects in a database
- schema: a conceptual blueprint of the entire database or a specific logical container for grouping objects like tables and views.

## What I understood
- Backup and migrations are essential for data safety and continuity. Using commands like BACKUP DATABASE, we can create copies of the database to prevent data loss and allow recovery in case of failures. This also connects to migrations, which help move or update database structures without losing existing data.

- Second, DDL (Data Definition Language) is the part of SQL responsible for shaping the database. It allows us to create, modify, and delete structures such as tables, indexes, and views. In other words, DDL defines how the data is organized rather than the data itself.
